# 游戏流程自检清单 (Game Loop Checklist)

在开发和测试阶段，请对照此清单检查游戏流程的完整性和逻辑闭环。

## 1. 启动与初始化
- [ ] **资源加载**: 能否正确加载所有 100 张角色立绘、5 张 Boss 立绘和背景图？
- [ ] **存档读取**: 能否正确读取用户的金币数、图鉴解锁状态和未完成的棋盘？
- [ ] **每日签到**: 是否在每天首次启动时弹出？签文是否随机且对应角色？

## 2. 核心战斗循环
- [ ] **生成逻辑**:
    - [ ] 空盘时是否主要生成 Lv.1 马？
    - [ ] 满盘（剩 <3 格）时是否触发“防死局”机制（掉落消除道具）？
    - [ ] 道具掉落的 Tier 是否匹配当前场上马匹的等级段？
- [ ] **移动与合成**:
    - [ ] 同等级合成是否正确升级 (Lv.N -> Lv.N+1)？
    - [ ] 道具合成是否生效 (马 + 青梅/马鞍/大炮)？
    - [ ] 特殊配方 (如桃园结义) 是否能正确检测相邻关系并触发？
- [ ] **技能释放**:
    - [ ] 技能是否扣除 Mana 或金币？
    - [ ] 技能效果 (消除、变身) 是否立即生效并刷新视图？

## 3. Boss 系统验证
- [ ] **触发条件**:
    - [ ] 年兽是否在第 12, 24... 回合准时出现？
    - [ ] 董卓是否在金币 > 5000 时出现？
    - [ ] 赵高是否在 3 次无效操作后出现？
- [ ] **Boss 行为**:
    - [ ] 倒计时结束时，干扰技能 (吞噬/锁格) 是否正确生效？
    - [ ] 玩家攻击是否正确扣除 Boss 血量？
    - [ ] 克制角色合成时是否有 3 倍伤害反馈？
- [ ] **击杀反馈**:
    - [ ] Boss 死亡是否掉落正确的 Tier 道具和金币？
    - [ ] 是否正确进入 Fever Time？

## 4. 经济与商店
- [ ] **金币获取**:
    - [ ] 消除 [马上有钱] 是否增加金币？
    - [ ] 结算界面金币是否正确入账？
- [ ] **商店购买**:
    - [ ] 购买道具后金币是否扣除？
    - [ ] 道具是否直接应用或放入棋盘空位？
    - [ ] 商店内容是否随回合刷新？

## 5. UI 与交互
- [ ] **图鉴**: 长按棋子是否显示正确的故事和祝福？
- [ ] **反馈**:
    - [ ] 合成成功是否有音效和特效？
    - [ ] Boss 来袭是否有全屏警告？
    - [ ] 结算分享图是否生成正确？

## 6. 异常处理
- [ ] **断网**: 弱网环境下是否能继续单机游玩？
- [ ] **闪退**: 游戏崩溃后重进，是否能恢复到上一步的棋盘状态？
