# B系：机甲钢魂 - 核心角色美术Prompt (Anime & Mecha Prompts)

本文件包含 B 系核心角色的详细 Nano Banana Prompt。
风格关键词：`Anime Style`, `Mecha`, `Super Robot`, `Cel Shaded`, `Vibrant`.

## Lv.32 乔尼慢舞 (Slow Dancer)
*来自《JOJO的奇妙冒险 SBR》。*

### Visual Description
*   **外观**: 一匹白色的阿帕卢萨马，身上有星星斑点。
*   **骑手**: 乔尼·乔斯达（蓝色衣服，戴着星星帽子，坐在轮椅或马背上）。
*   **特效**: 身上环绕着金色的回旋能量（Golden Spin），甚至有Act4替身虚影。
*   **风格**: 荒木飞吕彦的硬朗线条风格。

### Prompt
```
Pixel art sprite of Slow Dancer horse with Johnny Joestar rider from JJBA Steel Ball Run,
isometric view, 16-bit manga style,
white Appaloosa horse with star spots, rider in blue outfit with star hat,
golden spin energy effect spiraling around (golden rectangle ratio),
stand Tusk Act 4 faint silhouette behind,
dynamic pose, cel shaded, clean outlines, white background
```

## Lv.39 骷髅骑士 (Skull Knight)
*来自《剑风传奇》。*

### Visual Description
*   **外观**: 穿着古老骨骼盔甲的骑士，骑着同样穿着骨骼盔甲的战马。
*   **武器**: 手持唤水剑（Beherit Sword）。
*   **特效**: 幽灵般的蓝色气息，披风破烂但威严。
*   **风格**: 黑暗奇幻风格。

### Prompt
```
Pixel art sprite of Skull Knight riding skeletal warhorse from Berserk,
isometric view, 16-bit dark fantasy style,
skeletal armor plating on both rider and horse, flowing tattered cape,
holding Sword of Actuation (Beherit Sword),
eerie blue aura, metallic bone texture,
imposing stance, clean outlines, white background
```

## Lv.42 风云再起 (Fuunsaiki)
*来自《机动武斗传G高达》。*

### Visual Description
*   **外观**: 一匹真正的白马，但穿着高达风格的白色装甲。
*   **骑手**: 可能是神高达或东方不败（可选）。
*   **装甲**: 独角兽高达风格的白色装甲，带红色线条。
*   **底座**: 站在一个类似于高达格纳库的机械底座上。
*   **特效**: 身上散发着金色的“明镜止水”光辉。

### Prompt
```
Pixel art sprite of Fuunsaiki from G Gundam, a white horse wearing mobile suit armor,
isometric view, 16-bit super robot wars style,
white mechanical armor plating on legs and chest, unicorn horn,
glowing golden aura (Meikyo Shisui),
standing on a metallic base,
vibrant anime colors, cel shaded, clean outlines, white background
```

## Lv.43 人马高达 (Barbatos Lupus Rex - Centaur Mode idea)
*基于高达铁血的巴巴托斯或其他半人马高达概念。*

### Visual Description
*   **外观**: 巴巴托斯天狼座帝王形态，但下半身是机械马身（类似半人马）。
*   **武器**: 超巨大的锤矛（Mace）。
*   **细节**: 裸露的液压管线，野性的机械感，红色的眼光流苏。
*   **风格**: 铁血、硬核机甲风。

### Prompt
```
Pixel art sprite of Gundam Barbatos in centaur configuration,
isometric view, 16-bit mecha style,
white and blue mobile suit upper body, mechanical horse lower body,
wielding massive mace weapon, red eye glow effect,
exposed frame details, battle weathered texture,
heavy metal aesthetic, clean outlines, white background
```

## Lv.50 机械战马 (Mecha Horse)
*原创赛博朋克终极单位。*

### Visual Description
*   **外观**: 全金属构造，内部透出霓虹蓝光。
*   **武器**: 肩部搭载导弹巢，背部有激光炮。
*   **细节**: 复杂的液压杆和齿轮结构，赛博朋克风格。

### Prompt
```
Pixel art sprite of a futuristic Cyberpunk Mecha Horse,
isometric view, 16-bit sci-fi style,
chrome metal body with neon blue internal lighting,
mounted missile pods and laser cannons,
exposed hydraulics and gears,
high tech aesthetic, clean outlines, white background
```
