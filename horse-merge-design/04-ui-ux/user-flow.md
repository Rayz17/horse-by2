# 完整用户体验流程 (User Flow)

**设计原则**: 全程保持“新年贺岁”的喜庆氛围，无负面表达，无广告打扰。所有交互反馈均为正向激励。

## 1. 启动与大厅 (Launch & Lobby)
*   **Loading**:
    *   显示 Logo "马马合体 2026"。
    *   加载资源进度条 (0% -> 100%)。
    *   底部显示随机一条“马年冷知识”作为 Tips。
*   **每日签到 (Daily Sign) [弹窗]**:
    *   **触发**: 每天首次登录自动弹出。
    *   **交互**: 用户点击或摇晃手机 -> 签筒掉出一支签。
    *   **展示**: 显示签文 (如 "上上签") + 对应吉利角色立绘 (如 [马上有钱]) + 祝福语。
    *   **奖励**: 获得该角色 "体验卡" (本局开局送) + 少量金币。
    *   **操作**: 点击 "收下祝福" 关闭弹窗。
*   **主界面 (Home)**:
    *   **Play (开始)**: 屏幕中央巨大的核心按钮，带有呼吸特效。
    *   **Gallery (图鉴 - 核心玩法)**:
        *   **入口**: 显示收集进度 (e.g. 32/101) 和全图鉴奖励提示 (收集率奖励)。
        *   **图鉴墙**: 8x13 网格展示所有角色卡牌。
            *   **未解锁**: 显示灰色剪影 + 提示文本 (e.g. "需由 [Lv.5] 合成")。
            *   **已解锁**: 亮起卡牌，根据稀有度显示动态边框：
                *   **N (Common)**: 铜色边框。
                *   **R (Rare)**: 银色边框 + 微光。
                *   **SR (Super Rare)**: 金色边框 + 流光。
                *   **SSR (Ultra Rare)**: 钻石边框 + 粒子特效。
                *   **Hidden**: 紫色神秘边框 + 故障/特殊特效。
        *   **角色详情页 (点击卡牌)**:
            *   **顶部展示区**:
                *   **高清像素立绘**: 居中展示，背景为该角色的专属环境色。
                *   **交互**: 点击立绘播放 **攻击/技能/闲置** 动画 (Action/Skill/Idle)。
            *   **档案区**:
                *   名称、等级 (Lv.XX)、评级 (SSR)、原型出处。
                *   **马年寓意**: 专属的新年祝福语 (红色烫金字体，醒目展示)。
            *   **能力区**:
                *   **技能 (Skill)**: 图标 + 名称 + 详细数值描述。
                *   **特效 (VFX)**: 描述该角色的攻击特效 (e.g. "全屏流星雨")。
            *   **故事区 (Lore)**:
                *   详细的背景故事文本，揭示角色的性格与梗点。
    *   **Shop (纳福)**: 消耗金币购买被动天赋 (如: 初始等级提升、金币获取增加)。**无广告，无内购**。
    *   **Rank (金榜)**: 查看好友/世界分数。
    *   **Settings**: 音效/音乐/震动开关。

## 2. 备战阶段 (Preparation)
*   **触发**: 点击 "Play" 后弹出。
*   **选择初始**:
    *   默认: Lv.1 竹马 x2。
    *   天赋解锁: 可花费金币选择 Lv.5 开局，助你更快登顶。
*   **携带道具**: 购买本局可用的主动技能 (如: 大炮 x1, 刷新 x1)。
*   **开始**: 点击 "出击" 进入游戏。

---

## 3. 游戏主循环 (In-Game Loop)

### 3.1 核心界面 (HUD)
*   **顶部栏**:
    *   左侧: 当前分数 (Score)。
    *   右侧: 历史最高 (Best), 暂停按钮。
    *   **中央动态**: **Boss 预警/血条** (仅在 Boss 战时出现)。
*   **中央区**: **8x8 棋盘网格** (背景随等级动态切换)。
*   **底部栏**:
    *   **技能区**: 3 个技能图标 (冷却/次数显示)。
    *   **商店区**: 1 个“流动摊贩”图标，点击弹出购买菜单 (使用金币)。
    *   **任务提示**: 文字滚动 "当前目标: 合成 [赤兔]"。

### 3.2 玩家交互 (Interaction)
*   **移动/合成**: 手指在棋盘区域 **上下左右滑动**。
*   **查看详情**: **长按** 任意棋子 0.5秒 -> 弹出悬浮窗显示角色信息 (卡牌预览)。
*   **释放技能**: 点击底部技能图标 -> (若需要目标) 屏幕变暗，棋盘高亮可选目标 -> 点击目标释放。
*   **购买道具**: 点击商店图标 -> 弹出小窗 -> 点击金元宝购买 -> 道具飞入棋盘空位。

### 3.3 事件反馈 (Feedback)
*   **合成成功**: 棋子合并动画 + 音效 + "+Score" 飘字。
*   **解锁新角色**:
    *   游戏 **自动暂停**。
    *   **SSR/Hidden 登场特效**: 全屏金光/紫光切入 (Cut-in)。
    *   显示角色卡牌、Slogan、祝福语。
    *   **分享引导**: 按钮 "分享好运" (生成精美贺卡图片) / "继续游戏"。
*   **Boss 来袭**:
    *   全屏红光警报 + 喜庆的战鼓声。
    *   Boss 立绘从屏幕上方滑入。

## 4. 结算与分享 (Result & Share)

### 4.1 功德圆满 (Victory - 合成 Lv.101)
*   **表现**: 宇宙神驹奔跑动画，穿越星空，最终化为满天烟花。
*   **内容**:
    *   "恭喜通关！功德圆满！"
    *   本局耗时、步数、最高连击。
    *   获得 "2026 马年最强欧皇" 称号。
*   **操作**: "分享喜悦" / "无尽模式" / "返回大厅"。

### 4.2 纳福迎祥 (Board Full - 棋盘满)
*   **注意**: **严禁使用 "失败"、"Game Over"、"死局" 等负面词汇。**
*   **表现**: 棋盘暂时静止，弹出温馨提示。
*   **逆天改命 (复活)** (限1次):
    *   弹窗: "棋盘已满，是否请求 [神笔马良] 帮忙腾出空间？"
    *   **消耗**: 少量金币 (或每日免费1次)。**无广告**。
    *   **效果**: 随机消除 3x3 区域的低级棋子。
*   **最终结算 (若不复活)**:
    *   标题: "**福气满满**" (代替 Game Over)。
    *   **核心展示**:
        *   系统自动选取盘面上 **等级最高** 的角色 (例如 Lv.86 关羽赤兔)。
        *   显示该角色的立绘与 **专属新年祝福语** (例如: "祝您 [关羽赤兔] - 义薄云天，财运亨通！")。
        *   文案: "本局福星高照，收获满满！"
    *   **收益**: 金币结算入账。
    *   **操作**: "炫耀一下" (分享图包含最高角色和祝福) / "再来一局"。

### 4.3 社交分享：马年运势卡 (Fortune Card)
*   **触发**: 点击“炫耀一下”或“分享喜悦”时生成。
*   **设计理念**: 模仿传统的“求签/运势”图片，适合发朋友圈。
*   **内容结构**:
    *   **主图**: 玩家本局最高等级角色的精美像素立绘。
    *   **运势词**: 根据角色生成吉利话 (e.g. 关羽 -> "财运亨通", 桃花马 -> "桃花朵朵", 机械马 -> "科技致富")。
    *   **数据**: "本次合成了 XX 个角色，击败了 XX 个 Boss"。
    *   **底部**: 游戏 Logo + 二维码 (扫码即玩)。
*   **交互**: 生成图片后，提供“保存到相册”和“一键分享”按钮。

---

## 5. 再次挑战 (Replay)
*   结算页点击 "再来一局"。
*   跳过 Loading 和备战 (沿用上次配置)，直接重置网格，**秒开** 新局。
