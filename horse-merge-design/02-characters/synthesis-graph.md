# 核心合成逻辑与突变图谱 (Synthesis Graph)

本游戏的合成系统不仅仅是 `A + A = B`，而是引入了 **"道具催化"** 和 **"跨系突变"** 的化学反应机制。

---

## 1. 基础合成规则 (Basic Rules)

### 1.1 同系进化 (Tier Up)
*   **规则**: 两个相同等级、相同系谱的角色合成，等级 +1。
*   **公式**: `[系谱A] Lv.N + [系谱A] Lv.N = [系谱A] Lv.N+1`
*   **示例**: `Lv.1 竹马 + Lv.1 竹马 = Lv.2 某种A系进阶马` (具体视矩阵填充情况，若矩阵中有空缺，则跨级指向下一位A系角色)。
    *   *注*: 为简化游戏体验，通常合成结果指向 **Matrix** 表中该系谱的下一个 Available ID。

### 1.2 道具催化 (Item Catalyst)
*   **规则**: 马匹吞噬特定道具，发生形态改变（变身），等级可能大幅跳跃。
*   **公式**: `[马匹] + [道具] = [特殊角色]`

| 原材 (Base) | 催化剂 (Catalyst) | 结果 (Result) | 逻辑说明 |
|:---|:---|:---|:---|
| **任意马匹** | **[大炮]** (Cannon) | **Lv.36 马后炮** | 象棋梗/俗语梗。 |
| **任意马匹** | **[鹿牌]** (Deer Sign)| **Lv.70 指鹿为马** | 赵高技能或道具转化。 |
| **任意马匹** | **[老虎玩偶]** (Tiger)| **Lv.73 马马虎虎** | 缝合怪。 |
| **任意马匹** | **[画笔]** (Brush) | **Lv.82 神笔马良** | 赋予生命的画笔。 |
| **Lv.1 竹马** | **[青梅]** (Plum) | **Lv.20 伯乐相马** | 青梅竹马 -> 长大被伯乐相中 (跳级)。 |

## 2. 突变合成 (Mutation Recipes)

当不同系谱的高阶角色相遇时，会发生"突变"，生成融合了双方特征的强力角色。

### 2.1 赛博化 (Cyber-Evolution)
*   **配方**: **[A系 历史名马] + [B系 机甲单位]**
*   **逻辑**: 古代名马获得未来科技改造。
*   **示例**:
    *   `Lv.86 关羽赤兔` + `Lv.17 木马号/零件` -> **Lv.100 机械战马**

### 2.2 梗图具象化 (Meme Materialization)
*   **配方**: **[C系 玩梗] + [特定环境/道具]**
*   **示例**:
    *   `[马]` + `[马桶]` (环境互动) -> **Lv.52 马桶MT**

### 2.3 剧情重现 (Story Reenactment)
*   **配方**: **[角色A] + [角色B]**
*   **示例**:
    *   `Lv.81 白龙马` + `Lv.xx 唐僧(道具/NPC)` -> **Lv.81 取经天团** (觉醒形态)

## 3. 道具系统详解 (Item System)

为了支撑上述合成逻辑，以下道具必须在游戏循环中产出（掉落/商店）：

| 道具图标 | 名称 | 产出方式 | 作用 |
|:---|:---|:---|:---|
| 💣 | **大炮** | 商店 (200G) / Boss年兽掉落 | 合成 [马后炮]；或直接炸毁一个格子。 |
| 🐯 | **老虎** | 稀有掉落 / 随机事件 | 合成 [马马虎虎]。 |
| 🦌 | **鹿牌** | Boss赵高技能生成 (负面) | 用于合成 [指鹿为马] (变废为宝)。 |
| 🖌️ | **画笔** | 商店 (500G) | 合成 [神笔马良]。 |
| 🍈 | **青梅** | 低级掉落 | 快速将 Lv.1 提升至 Lv.20。 |
| 💰 | **金元宝**| 掉落 | 吞噬获得大量金币，附加 [马上有钱] Buff。 |
| 🐵 | **猴子** | 稀有掉落 | 吞噬附加 [马上封侯] Buff (升官发财)。 |

## 4. 失败与惩罚转化 (Failure Management)

*   **废棋**: 当 Boss 赵高发动技能，会将场上的马变成 **Lv.0 [鹿]**。
    *   **处理**: 鹿无法移动，无法常规合成。
    *   **解法**: 购买或等待 **[鹿牌]** 或使用消除道具。或者当两个 [鹿] 相邻时，自动消除并仅返还 1 金币。
