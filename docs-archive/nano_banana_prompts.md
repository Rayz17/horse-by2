# Nano Banana 专用生成清单 (Prompts V5.1 - Wide Spacing & Clean BG)

**更新说明**:
*   **增加间距**: 加入了 `wide spacing between poses`, `far apart` 等关键词，防止角色粘连。

*   **纯净背景**: 强化 `pure white background`，防止出现黑色背景框。
