# Nano Banana 专用生成清单 (UI & Items V6.0)

**说明**:
*   **用途**: 用于生成游戏界面、图标、道具和特效。
*   **风格**: 积极鼓舞，AI 未来感与传统美好融合 (AI Future x Traditional Beauty)。去除过重的春节元素，保留马年特色。
*   **格式**: 直接复制 Prompt 到 AI 生成工具。
*   **通用后缀**: 大部分图标类资源已包含 `pure white background` 以方便去底。
