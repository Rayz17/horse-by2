# 马马合体：全谱系角色矩阵 (Character Matrix)

**设计理念**: 摒弃单纯的 Lv.1-100 线性升级，采用 **"四大系谱 x 五大阶级"** 的矩阵结构。
等级 (Lv) 仅代表合成深度，同阶级角色强度相当，但功能不同。

## 1. 四大系谱 (Factions)
*   **[A] 帝王将相 (Warlords)**: 历史名将与他们的坐骑。主打物理输出、统帅光环。
*   **[B] 机甲钢魂 (Mecha/Anime)**: 动漫、游戏、科幻题材。主打远程、AOE、特殊机制。
*   **[C] 玩梗高手 (Memes)**: 谐音梗、网络流行语、成语。主打控制、辅助、搞怪效果。
*   **[D] 神话传说 (Myths)**: 东西方神话生物。主打回复、Buff、魔法伤害。

## 3. 重点角色调整说明 (Key Changes)

### 动漫/机甲系 (B系) 增强
*   **Lv.66 骷髅骑士 (Skull Knight)**: 来自《剑风传奇》，骑着骷髅战马的神秘骑士。
*   **Lv.80 风云再起 (Fuunsaiki)**: 来自《G高达》，高达驾驶的高达马。
*   **Lv.88 拉奥黑王 (Raoh & Kokuoh)**: 来自《北斗神拳》，世纪末霸主与巨型黑马。
*   **Lv.95 刃马一体 (Jinba Ittai)**: 来自《机战OG》，大曾伽+龙卷，男人的浪漫。
*   **Lv.7 木马号 (White Base)**: 高达0079母舰，长腿的战舰 (调整至 Tier 1)。

### 玩梗/现实系 (C系) 修正
*   **Lv.19 马冬梅**:  Tier 1 隐藏款 (Hidden)。大妈骑马，满头问号。
*   **Lv.68 二马弟弟**: 现实朋友梗，Tier 4 隐藏款 (Hidden)。
*   **Lv.93 三驾马车**: Tier 5 隐藏款 (Hidden)。三位马姓互联网大佬驾驶的科幻战车。
*   **Lv.40 牛马打工人**: Tier 2 隐藏款 (Hidden)。替代原佐德。

### 历史/神话系 (A/D系) 优化
*   **Lv.81 取经天团**: 原唐僧白龙。唐僧骑着白马，影子是龙，强调“师徒合一”。
*   **Lv.79 捷影 (Shadowfax)**: 替代爱马仕，作为 Tier 4 的 SSR 角色。

## 4. 合成与道具逻辑 (Synthesis & Items)

### 4.1 核心道具 (Key Items)
道具不再只是简单的升级材料，而是**合成配方**的关键部分。

| 道具名 | 来源 | 用途 |
|:---|:---|:---|
| **[青梅]** | 掉落/商店 | Lv.1 竹马 + 青梅 = Lv.20 伯乐相马 (跳级) |
| **[大炮]** | 掉落/商店 | 任意马 + 大炮 = Lv.36 马后炮 |
| **[老虎]** | 稀有掉落 | 任意马 + 老虎 = Lv.73 马马虎虎 |
| **[鹿牌]** | Boss赵高 | 任意马 + 鹿牌 = Lv.70 指鹿为马 |
| **[画笔]** | 商店(贵重) | 任意马 + 画笔 = Lv.82 神笔马良 |
| **[金元宝]**| 掉落 | 任意马 + 金元宝 = **[马上有钱]** (Buff状态，非新角色) |

### 4.2 突变公式 (Mutation Examples)
*   **[A系] + [B系] = 赛博化**:
    *   例如: [Lv.86 关羽赤兔] + [Lv.7 木马号] = **[Lv.100 机械战马]** (赤兔的终极赛博形态)。
*   **[C系] + [特定道具] = 梗图具象化**:
    *   [马] + [马桶] = [Lv.52 马桶MT]。

## 5. Boss 闭环设计
*   **赵高 (Zhao Gao)**: 技能是将你场上的 [马] 变成 [Lv.0 鹿]。
    *   **应对**: 合成 [Lv.70 指鹿为马] 可以反制赵高，对其造成巨额伤害。
*   **年兽 (Nian)**: 怕响声。
    *   **应对**: 场上存在 [Lv.36 马后炮] 或 [大炮] 时，年兽防御力大幅降低。
*   **董卓 (Dong Zhuo)**: 贪婪。
    *   **应对**: 使用 [Lv.38 黑马王子] (代替美人计) 诱惑他。
