# 01-core-mechanics/combat-logic.md

# 战斗与生存机制 (Combat & Survival)

为了解决传统 2048 后期枯燥的问题，本游戏引入“数值战斗”机制。

## 1. 敌方单位 (Enemy Units)
敌人也是棋盘上的棋子 (Tile)，占用格子，但不能被玩家控制移动。

| 敌人类型 | 行为逻辑 | 数值(HP/ATK) | 出现条件 |
|:---|:---|:---|:---|
| **绊马索** (Trap) | 静止不动。马匹经过时被“定身”3回合（无法移动/合成）。 | N/A | 随机生成 |
| **恶狼** (Wolf) | 静止不动。每3回合等级+1（成长）。 | Lv.1 ~ Lv.10 | 早期阶段 |
| **敌将** (General)| 每回合向最近的马匹移动一格。 | Lv.10 ~ Lv.50 | 进阶阶段 |
| **Boss** (Dong Zhuo)| 占据 2x2 格子。每回合吞噬周围一圈棋子。 | HP: 100 | 特定关卡 |

## 2. 战斗判定 (Combat Resolution)
当玩家滑动屏幕，使 **己方马匹 (Lv.A)** 撞向 **敌方单位 (Lv.B)** 时：

*   **胜利 (A >= B)**:
    *   敌方单位消失。
    *   己方马匹保留，且获得经验（可能直接升级或获得Buff）。
    *   掉落：金币 (Gold) 或 技能能量 (Mana)。
    *   *视觉反馈*：马匹冲撞特效，敌人碎裂。

*   **失败 (A < B)**:
    *   **己方马匹死亡**（消失）。
    *   敌方单位保留，且可能回血/升级。
    *   *视觉反馈*：马匹惨叫消失，屏幕震动。

## 3. 失败判定 (Game Over)
游戏结束的条件不仅仅是“格子填满”，还包括：
1.  **困局**: 格子填满，且无任何可合成项，且无技能可用。
2.  **核心被毁**: 如果模式是“护送唐僧”，当“唐僧”棋子被敌人吃掉时，立即判负。

# 01-core-mechanics/economy-loop.md

# 经济循环系统 (Economy Loop)

## 1. 局内循环 (Session Loop) - "法力值 (Mana)"
*   **获取**:
    *   每次成功合成 (Merge): +1 Mana
    *   触发连击 (Combo): +5 Mana
    *   击杀敌人: +10 Mana
*   **消耗**:
    *   释放主动技能（踢飞、刷新、指定合成）。
*   **归零**: 每局游戏结束后清零。

## 2. 局外循环 (Meta Loop) - "金币 (Gold)"
*   **获取**:
    *   结算时根据分数折算。
    *   达成成就 (Achievement)。
    *   每日签到 / 观看广告。
*   **消耗**:
    *   **解锁初始角色**: 开局不再是 Lv.1 牛犊，而是 Lv.5 乌骓（赢在起跑线）。
    *   **购买被动天赋**: 如“合成暴击率+5%”、“开局自带100 Mana”。
    *   **抽奖**: 抽取特殊的皮肤或装饰（不影响数值）。

# 01-core-mechanics/progression-stages.md

# 关卡进程与动态难度 (Progression)

为了避免 8x8 棋盘一开始过于空旷，游戏采用动态扩容机制。

## 阶段一：草原起步 (The Grassland)
*   **网格**: 4x4
*   **目标**: 合成出 Lv.10 (马路/马甲)
*   **敌人**: 无
*   **体验**: 纯粹的 2048 教学，节奏快。
*   **晋级**: 一旦出现 Lv.10 棋子，棋盘四周会有“地震”动画，扩容至 5x5。

## 阶段二：乱世争锋 (The Battlefield)
*   **网格**: 5x5 -> 6x6
*   **目标**: 合成出 Lv.25 (赤兔)
*   **敌人**: 出现“绊马索”和“恶狼”。
*   **机制**: 引入战斗。玩家需要学会用高等级马去撞狼，而不是只顾着合成。

## 阶段三：神魔降临 (The Mythic)
*   **网格**: 6x6 -> 8x8
*   **目标**: 合成 Lv.80 (麒麟) -> Lv.100
*   **敌人**: 出现主动移动的“敌将”和 Boss。
*   **机制**: 必须利用“突变”和“技能”来清场，否则棋盘会被 Boss 吞噬殆尽。

# 游戏流程纸上模拟 (Paper Prototype Simulation)

## 场景设定
*   **玩家**: Ray (老手)
*   **关卡**: 阶段二 (5x5 网格)
*   **当前状态**: 棋盘半满，拥有一匹 Lv.15 (照夜白) 和若干杂鱼。

## 操作流程模拟

| 回合 | 玩家操作 | 系统/棋盘反馈 | 逻辑分析 |
|:---|:---|:---|:---|
| **T-01** | **向右滑动** | 所有棋子右移。两个 Lv.3 合成 Lv.4。随机生成一个 Lv.1 在左侧。 | 常规合成，积攒 Mana +1。 |
| **T-02** | **向上滑动** | 棋子移动。**警告**: 棋盘中间随机生成了一只 **Lv.10 恶狼**。 | 敌人生成。此时玩家最高的马是 Lv.15。 |
| **T-03** | **思考** | 玩家发现 Lv.15 在右下角，狼在中间。如果直接左滑，Lv.15 会撞到狼。 | 战术判断：Lv.15 > Lv.10，可以吃掉。 |
| **T-04** | **向左滑动** | Lv.15 撞击 Lv.10 恶狼。**战斗触发**！<br>狼被消灭，掉落 10 Mana。Lv.15 升级为 Lv.16。 | 战斗收益：利用高等级马清理障碍并获利。 |
| **T-05** | **向下滑动** | 此时棋盘拥挤。触发了 **突变配方**：Lv.4 竹马 + Lv.4 竹马。<br>**特效**: 屏幕闪过粉色光芒，合成出 **Lv.Special 青梅**。 | 突变时刻：非线性升级带来的惊喜。 |
| **T-06** | **技能释放** | 此时 Mana 满 50。玩家点击技能【指鹿为马】。<br>将棋盘上一个碍事的 Lv.1 石头变成了 Lv.1 马。 | 资源消耗：利用 Mana 解除死局风险。 |
| **T-07** | **失误** | 玩家手滑向右。一个 Lv.2 小马撞上了新生成的 Lv.20 敌将。<br>**惨叫声**，Lv.2 小马阵亡。 | 惩罚机制：低级撞高级，损失棋子。 |
| ... | ... | ... | ... |
| **T-End** | **结算** | 棋盘填满，Game Over。<br>显示分数: 12,450。<br>获得金币: 124。<br>解锁新图鉴: 青梅。 | 循环闭环：金币用于强化下一次开局。 |

## 闭环检查结论
1.  **输入**: 滑动、点击技能。
2.  **反馈**: 合成升级、战斗结果、资源增减。
3.  **循环**: 局内(Mana)支持生存 -> 生存带来高分 -> 局外(Gold)支持强化 -> 强化带来更远进度。
4.  **目标**: 短期(消灭眼前的狼)、中期(合成赤兔)、长期(全图鉴/排行榜)。

**结论**: 逻辑闭环成立。
