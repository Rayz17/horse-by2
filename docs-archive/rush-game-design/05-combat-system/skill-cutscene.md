# 技能特写演出系统

## 设计理念

参考《超级机器人大战》系列的必杀技演出，在释放技能2（必杀技）时播放华丽的特写演出，提升战斗爽快感和角色魅力。

---

## 演出规格

### 时间限制

| 阶段 | 时长 |
|------|------|
| 演出总时长 | 1.5-2.5秒 |
| 画面切入 | 0.2秒 |
| 技能动画 | 1.0-2.0秒 |
| 画面切回 | 0.2秒 |

### 画面尺寸

| 元素 | 尺寸 |
|------|------|
| 特写背景 | 640×360像素 |
| 角色立绘 | 192×256像素 |
| 技能特效 | 全屏覆盖 |

---

## 演出流程

### 标准必杀技演出

```
1. 触发 → 游戏暂停
2. 闪白过渡 (0.1秒)
3. 特写背景铺开
4. 角色立绘登场 (从侧边滑入)
5. 技能名称显示 (日文+中文)
6. 技能动画播放
7. 伤害数字显示
8. 闪白过渡 (0.1秒)
9. 恢复游戏
```

### 演出元素

1. **特写背景**: 放射状线条 + 角色主题色
2. **角色立绘**: 动态姿势，表情激动
3. **技能名称**: 日文原名 + 中文翻译
4. **技能特效**: 全屏华丽粒子效果
5. **配音/音效**: 角色喊招 + 打击音效

### 刃马一体 - 一刀両断斬

**演出时长**: 2.0秒

**分镜**:
```
[0.0-0.2s] 闪白，屏幕暗转
[0.2-0.5s] 藏青色放射背景展开
          大曾伽立绘从右侧滑入
          台词: "我が剣は…天地を断つ剣！"

          白色能量凝聚于刀刃

          全屏白色斩击波

[1.6-1.8s] 大曾伽收刀姿势
```

## 技能名称显示规范

### 显示格式

```
┌─────────────────────┐
│   一刀両断斬        │  ← 日文原名 (大字)
│  Single Bisection   │  ← 英文名 (可选小字)
└─────────────────────┘
```

### 字体规范

| 元素 | 字体 | 大小 |
|------|------|------|
| 日文名 | 像素书法体 | 48px |
| 中文名 | 像素黑体 | 24px |
| 边框 | 金色描边 | 2px |

## 性能优化建议

1. **预加载立绘** - 选择角色时加载
2. **粒子池化** - 复用粒子对象
3. **异步渲染** - 不阻塞游戏主线程
4. **可选关闭** - 设置中提供关闭选项
