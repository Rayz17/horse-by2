# 战斗机制设计

## 战斗概述

《马年狂奔》的战斗系统区别于传统跑酷游戏的"躲避为主"，采用**主动战斗+自动战斗结合**的设计。

---

## 攻击类型

### 1. 自动普攻

| 属性 | 设置 |
|------|------|
| 触发条件 | 敌人进入攻击范围 |
| 攻击范围 | 角色前方100像素 |
| 攻击间隔 | 0.5秒 |
| 伤害 | 角色基础攻击力 |

**特点**: 玩家无需操作，专注于移动和技能

### 2. 技能1 (主动技能)

| 属性 | 设置 |
|------|------|
| 触发条件 | 玩家点击中央区域 |
| 冷却时间 | 8-15秒（角色差异） |
| 效果类型 | 范围攻击/穿透/召唤等 |
| 特写演出 | 无（即时释放） |

### 3. 技能2 (必杀技)

| 属性 | 设置 |
|------|------|
| 触发条件 | 玩家点击右侧区域 |
| 冷却时间 | 18-25秒（角色差异） |
| 效果类型 | 超强单体/全屏/变身等 |
| 特写演出 | **有**（1-2秒演出） |

## 伤害计算公式

### 基础伤害

```
基础伤害 = 角色攻击力 × 技能倍率
```

### 最终伤害

```
最终伤害 = 基础伤害 × 暴击倍率 × 属性克制 × 连击加成 - 敌人防御
```

### 参数说明

| 参数 | 数值范围 |
|------|---------|
| 暴击率 | 5%-30% |
| 暴击倍率 | 1.5-2.0 |
| 属性克制 | 0.5/1.0/1.5 |
| 连击加成 | 1.0-1.5 |

## 角色属性系统

### 6项基础属性

| 属性 | 缩写 | 说明 | 范围 |
|------|------|------|------|
| 生命值 | HP | 角色血量 | 100-300 |
| 攻击力 | ATK | 普攻和技能基础伤害 | 10-50 |
| 防御力 | DEF | 减少受到伤害 | 5-30 |
| 速度 | SPD | 移动速度 | 80-120% |
| 暴击率 | CRI | 暴击概率 | 5-30% |
| 技能CD | CDR | 技能冷却减少 | 0-30% |

### 角色类型特征

| 类型 | HP | ATK | DEF | SPD | 特点 |
|------|-----|-----|-----|-----|------|
| 骑乘型 | 高 | 中 | 高 | 中 | 稳定耐久 |
| 奔跑型 | 中 | 高 | 低 | 高 | 快速输出 |
| 飞行型 | 低 | 中 | 低 | 中 | 可飞越障碍 |

## 敌人设计

### 小兵 (Minion)

| 属性 | 数值 |
|------|------|
| HP | 20-50 |
| ATK | 5-10 |
| 击杀分数 | 100 |
| 掉落金币 | 1-3 |

**行为模式**:
- 水平移动或固定站立
- 接触玩家造成伤害
- 被动等待攻击

### 精英怪 (Elite)

| 属性 | 数值 |
|------|------|
| HP | 100-200 |
| ATK | 15-25 |
| 击杀分数 | 500 |
| 掉落金币 | 5-10 |

**行为模式**:
- 有攻击前摇动画
- 可能有远程攻击
- 死亡有特殊效果

### Boss

| 属性 | 数值 |
|------|------|
| HP | 1000-3000 |
| ATK | 30-50 |
| 击杀分数 | 5000 |
| 掉落 | 大量金币+稀有道具 |

**行为模式**:
- 多阶段战斗
- 多种攻击模式
- 有愤怒机制

## 连击系统

### 连击计数

| 行为 | 连击增加 |
|------|---------|
| 击杀敌人 | +1 |
| 收集金币 | +1 |
| 使用技能命中 | +2 |
| 无伤通过障碍 | +0.5 |

### 连击重置

- 3秒内无任何击杀/收集
- 受到伤害

### 连击奖励

| 连击数 | 分数倍率 | 特效 |
|--------|---------|------|
| 5 | ×1.5 | "GOOD" 提示 |
| 10 | ×2.0 | "GREAT" 提示 |
| 15 | ×2.5 | "EXCELLENT" 提示 |
| 20 | ×3.0 | "PERFECT" 提示 + 闪光 |
| 30+ | ×3.0 | "UNSTOPPABLE" + 火焰特效 |

## 无敌帧与伤害判定

### 无敌帧触发

| 情况 | 无敌时长 |
|------|---------|
| 受伤后 | 1秒 |
| 技能2释放中 | 演出全程 |
| 道具触发 | 3-5秒 |
| 复活后 | 3秒 |

### 碰撞箱设计

```
角色碰撞箱: 宽32像素 × 高48像素 (中心对齐)
敌人碰撞箱: 各敌人独立设计
攻击判定框: 角色碰撞箱前方延伸
```

## 治疗与恢复

### 恢复来源

| 来源 | 恢复量 |
|------|--------|
| 生命药水 | 30 HP |
| 饺子 | 50 HP |
| 蟠桃 | 全满 |
| 技能被动 | 角色特定 |

### 恢复上限

- 不可超过角色最大HP
- 无过量治疗机制
