## 道具生成规则

### 场景生成

```
每100米生成检查:
1. 必定生成: 5-10个金币组
2. 概率生成: 1个道具 (30%恢复, 20%增益)
3. 特殊位置: 隐藏区域/高处有稀有道具
```

### 金币排列模式

| 模式 | 描述 | 用途 |
|------|------|------|
| 直线 | 水平排列5-10个 | 引导路线 |
| 弧线 | 跳跃轨迹排列 | 教学跳跃 |
| 圆形 | 环形排列 | 标记重要位置 |
| 箭头 | 指向排列 | 引导前进 |

## 道具平衡考量

### 恢复道具频率

- 确保平均每次受伤后300米内能获得恢复
- Boss战前200米保证有1个恢复道具

### 增益道具价值

- 增益道具应该能明显改变局势
- 但不能过于强力导致无脑通关

### 货币经济

- 单局金币获取: 200-500
- 角色解锁成本: 1000-5000
- 确保F2P玩家可以解锁所有角色
