# UI与视觉规格

## 屏幕适配

### 目标分辨率

| 设备类型 | 分辨率 | 宽高比 |
|---------|--------|--------|
| 设计基准 | 1280×720 | 16:9 |
| iPhone | 自适应 | 各种 |
| Android | 自适应 | 各种 |

### 适配策略

- **横屏游戏**: 高度固定720px，宽度自适应
- **竖屏UI**: 宽度固定，高度自适应
- **安全区**: 内边距20px，避免刘海/圆角

## 弹窗规范

### 弹窗尺寸

| 类型 | 尺寸 |
|------|------|
| 提示弹窗 | 300×180 |
| 确认弹窗 | 340×220 |
| 结果弹窗 | 400×500 |
| 全屏弹窗 | 100%×100% |

### 弹窗动画

- **进入**: 从中心放大 0.2秒
- **退出**: 向中心缩小 0.15秒
- **背景**: 渐变变暗 0.2秒

## 动画规范

### 界面过渡

| 过渡类型 | 时长 | 曲线 |
|---------|------|------|
| 页面切换 | 0.3s | ease-out |
| 弹窗显示 | 0.2s | ease-out |
| 元素高亮 | 0.15s | linear |
| 按钮反馈 | 0.1s | ease-in-out |

### 游戏内动画

| 动画类型 | 帧率 | 备注 |
|---------|------|------|
| 角色动画 | 12 FPS | 像素风格 |
| 特效动画 | 30 FPS | 粒子效果 |
| UI动画 | 60 FPS | 流畅交互 |
