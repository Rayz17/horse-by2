# 游戏阶段系统

## 关卡结构

每条赛道包含3个阶段 + 1个Boss战：

```
阶段1 (起步) → 阶段2 (加速) → 阶段3 (高潮) → Boss战 → 通关
```

---

## 阶段详细设计

### 阶段1: 起步期 (0-500米)

| 属性 | 设置 |
|------|------|
| 持续距离 | 500米 |
| 移动速度 | 基础速度 ×1.0 |
| 敌人密度 | 低（每100米2-3个小兵） |
| 障碍密度 | 低 |
| 道具出现率 | 高（帮助新手） |

**设计目标**: 让玩家熟悉操作，建立信心

### 阶段2: 加速期 (500-1500米)

| 属性 | 设置 |
|------|------|
| 持续距离 | 1000米 |
| 移动速度 | 基础速度 ×1.2 |
| 敌人密度 | 中（每100米4-5个小兵，1个精英） |
| 障碍密度 | 中 |
| 道具出现率 | 中 |

**设计目标**: 提升紧张感，考验操作

### 阶段3: 高潮期 (1500-2500米)

| 属性 | 设置 |
|------|------|
| 持续距离 | 1000米 |
| 移动速度 | 基础速度 ×1.4 |
| 敌人密度 | 高（每100米6-8个小兵，2个精英） |
| 障碍密度 | 高 |
| 道具出现率 | 低 |

**设计目标**: 极限考验，刺激体验

### Boss战 (2500米)

| 属性 | 设置 |
|------|------|
| 场景 | 固定战斗区域，停止滚动 |
| Boss血量 | 根据赛道难度调整 |
| 战斗时长 | 60-120秒 |
| 失败条件 | 玩家死亡 |
| 胜利条件 | Boss血量归零 |

## 速度系统

### 基础速度
- 奔跑型: 300 像素/秒
- 骑乘型: 320 像素/秒
- 飞行型: 280 像素/秒（但可飞越障碍）

### 速度修正

| 阶段 | 速度倍率 |
|------|---------|
| 阶段1 | ×1.0 |
| 阶段2 | ×1.2 |
| 阶段3 | ×1.4 |
| Boss战 | ×0（固定场景） |

### 道具影响
- 快马加鞭: +50% 速度，持续5秒
- 减速陷阱: -30% 速度，持续3秒

## 无限模式

通关任意赛道后解锁无限模式：

| 属性 | 设置 |
|------|------|
| 结构 | 无限循环，难度渐进 |
| 速度 | 每1000米增加5%，上限×2.0 |
| 敌人 | 随机生成，密度渐增 |
| Boss | 每2000米出现一个随机Boss |
| 目标 | 追求最远距离/最高分数 |

## 分数计算

### 基础得分

| 行为 | 分数 |
|------|------|
| 奔跑 | 10分/100米 |
| 击杀小兵 | 100分 |
| 击杀精英 | 500分 |
| 击杀Boss | 5000分 |
| 收集金币 | 10分/枚 |

### 连击加成

| 连击数 | 加成倍率 |
|--------|---------|
| 1-4 | ×1.0 |
| 5-9 | ×1.5 |
| 10-14 | ×2.0 |
| 15-19 | ×2.5 |
| 20+ | ×3.0 |

连击在3秒内无击杀/收集会重置

### 通关加成

| 条件 | 加成 |
|------|------|
| 通关赛道 | +2000分 |
| 无伤通关 | ×1.5 |
| 时间加成 | 剩余时间×100分 |

## 复活机制

### 复活选项
1. **观看广告复活** - 每局限1次
2. **使用复活币** - 消耗道具

### 复活后状态
- 血量恢复50%
- 3秒无敌时间
- 保持当前位置
