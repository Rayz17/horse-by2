# 核心设计理念

## 游戏定位

**马年狂奔** (Year of the Horse Rush)

一款为微信移动端优化的**像素风横版跑酷+战斗游戏**，融合中国马年文化、经典ACG角色致敬、与赛博朋克美学。

### 核心卖点

1. **31个马主题角色** - 覆盖神话、动漫、游戏、网络梗多个领域
2. **战斗跑酷** - 不只是躲避，更要战斗击杀敌人
3. **技能特写演出** - 参考超级机器人大战的华丽必杀技演出
4. **马年祝福系统** - 收集成就获得新年祝福语
5. **社交分享** - 微信朋友圈传播，春节病毒式营销

## 目标用户

### 主要用户
- 18-35岁中国年轻人
- 对ACG文化有一定了解
- 春节期间寻找娱乐消遣
- 微信重度用户

### 次要用户
- 休闲手游玩家
- 怀旧像素游戏爱好者
- 收集控（角色收集）

---

## 游戏体验目标

### 核心循环 (30秒)
```
选择角色 → 开始奔跑 → 跳跃/攻击/技能 → 击杀敌人/收集金币 → 死亡或通关 → 查看成绩 → 再来一局
```

### 单局时长
- 目标: 2-5分钟
- 最短: 30秒（新手失败）
- 最长: 10分钟（高手完美通关）

### 情感曲线
1. **起步期** (0-30s): 熟悉操作，建立节奏感
2. **成长期** (30s-2min): 难度上升，开始紧张刺激
3. **高潮期** (2-4min): Boss战/密集敌人，全神贯注
4. **结算期**: 成就感/遗憾感，分享冲动

## 差异化设计

### vs 传统跑酷游戏
| 传统跑酷 | 马年狂奔 |
|---------|---------|
| 只能躲避障碍 | 可以战斗击杀敌人 |
| 单一角色/换皮 | 31个独特角色各有技能 |
| 简单得分机制 | 连击+击杀+收集复合评分 |
| 无限模式为主 | 关卡模式+无限模式 |

### vs 横版动作游戏
| 横版动作 | 马年狂奔 |
|---------|---------|
| 复杂操作 | 简化3点触控 |
| 长时间关卡 | 单局2-5分钟 |
| 重度游戏 | 轻度休闲 |

## 操作设计

### 3点触控系统

```
┌─────────────────────────────────────┐
│                                     │
│     [游戏画面区域]                   │
│                                     │
├───────────┬───────────┬─────────────┤
│   跳跃    │   技能1   │    技能2    │
│  (点击)   │  (点击)   │   (点击)    │
│           │           │  (长按蓄力)  │
└───────────┴───────────┴─────────────┘
     左侧       中央         右侧
```

### 操作映射
| 区域 | 操作 | 效果 |
|------|------|------|
| 左侧 | 点击 | 跳跃（可二段跳） |
| 中央 | 点击 | 技能1（主动技能） |
| 右侧 | 点击 | 技能2（必杀技） |
| 右侧 | 长按 | 蓄力技能（部分角色） |

### 自动机制
- **自动奔跑** - 角色自动向右移动
- **自动普攻** - 接近敌人时自动攻击
- **自动拾取** - 金币/道具自动吸附

## 屏幕方向

| 界面 | 方向 | 原因 |
|------|------|------|
| 主菜单 | 竖屏 | 微信内嵌浏览器默认 |
| 角色选择 | 竖屏 | 方便单手操作 |
| **游戏战斗** | **横屏** | 更好的视野和操作空间 |
| 结算界面 | 竖屏 | 方便分享截图 |

## 付费设计 (轻度)

### 免费内容
- 8个初始角色
- 3条赛道
- 基础游戏体验

### 付费/激励内容
- 观看广告解锁角色
- 成就解锁角色
- 红包/打赏支持（可选）
