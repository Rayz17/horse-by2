# 马年文化主题设计

## 马年成语祝福系统

### 核心成语 (8个)

| 成语 | 拼音 | 含义 | 解锁条件 |
|------|------|------|---------|
| 马到成功 | mǎ dào chéng gōng | 立刻成功 | 首次通关任意赛道 |
| 龙马精神 | lóng mǎ jīng shén | 精力旺盛 | 无伤通关 |
| 一马当先 | yī mǎ dāng xiān | 领先第一 | 排行榜前100 |
| 万马奔腾 | wàn mǎ bēn téng | 声势浩大 | 累计击杀1000敌人 |
| 老马识途 | lǎo mǎ shí tú | 经验丰富 | 完成所有赛道 |
| 快马加鞭 | kuài mǎ jiā biān | 加快速度 | 单局速度加成10次 |
| 千军万马 | qiān jūn wàn mǎ | 兵力强大 | 解锁所有角色 |
| 天马行空 | tiān mǎ xíng kōng | 思想自由 | 使用飞行角色累计飞行10000米 |

## 春节视觉元素

### 颜色方案

**主题色**: 赛博朋克霓虹 + 中国传统节日色

| 元素 | 颜色 | 用途 |
|------|------|------|
| 霓虹青 | #00FFFF | 科技感主色 |
| 霓虹紫 | #FF00FF | 科技感辅色 |
| 春节红 | #FF2D2D | 节日氛围 |
| 金色 | #FFD700 | 金钱、祝福 |
| 深蓝 | #1A1A2E | 背景底色 |

### 节日装饰元素

- 霓虹灯笼
- 电子春联
- 赛博烟花
- 全息福字
- LED红包

## 红包系统

### 游戏内红包

| 红包类型 | 内容 | 获取方式 |
|---------|------|---------|
| 新手红包 | 500金币 | 首次登录 |
| 每日红包 | 100-300金币 | 每日登录 |
| 成就红包 | 随机金币 | 完成成就 |
| 排名红包 | 大量金币 | 周榜前列 |

### 分享红包机制

1. 玩家分享游戏到朋友圈
2. 朋友点击链接进入游戏
3. 分享者获得"分享红包"奖励
4. 被邀请者获得"欢迎红包"

## 春节限定内容

### 限定角色 (2个)

| 角色 | 获取方式 | 限定时间 |
|------|---------|---------|
| 年兽 | 击败年兽Boss | 春节期间 |
| 福娃骑士 | 累计登录7天 | 春节期间 |

### 限定赛道

- **春节大街** (T6) 在春节期间有额外装饰效果
- 烟花更密集
- 红包掉落率+50%
- 金币闪烁福字效果

### 限定活动

| 活动 | 内容 | 奖励 |
|------|------|------|
| 新年连续登录 | 连续7天登录 | 限定角色皮肤 |
| 万马贺新春 | 全服累计击杀 | 全服发放金币 |
| 新年祝福墙 | 分享祝福语 | 随机奖励 |

## 音效设计

### 春节特色音效

| 场景 | 音效 |
|------|------|
| 游戏开始 | 鞭炮声 + 锣鼓声 |
| 获得金币 | 红包拆开声 |
| 技能释放 | 烟花升空声 |
| 击败Boss | 震天锣鼓 |
| 通关 | 喜庆音乐 |

### 背景音乐风格

- **主菜单**: 电子版春节序曲混音
- **战斗中**: 节奏感强的电子+民乐融合
- **Boss战**: 激昂的战斗BGM

## 新年倒计时

在春节前7天至除夕期间：

### 倒计时特效
- 主菜单显示"距离马年还有X天"
- 每天解锁一个隐藏彩蛋
- 除夕当天全服庆祝特效

### 彩蛋内容
| 天数 | 彩蛋 |
|------|------|
| 7天 | 解锁福字背景 |
| 6天 | 解锁春联边框 |
| 5天 | 解锁灯笼装饰 |
| 4天 | 解锁鞭炮特效 |
| 3天 | 解锁烟花特效 |
| 2天 | 解锁红包雨 |
| 1天 | 解锁限定角色预告 |
| 除夕 | 全部限定内容上线 |
