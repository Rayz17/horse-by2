# 开发计划

## MVP范围定义

### MVP目标
构建一个可玩、可分享的最小完整游戏版本

### MVP包含内容

| 类别 | MVP内容 | 数量 |
|------|---------|------|
| 角色 | 初始解锁+易解锁角色 | 12个 |
| 赛道 | 代表性赛道 | 3条 |
| 敌人 | 小兵+精英+Boss | 6种 |
| 道具 | 核心道具 | 8种 |
| 功能 | 核心游戏流程 | - |

## 开发阶段划分

### 第一阶段: 基础框架 (1-2周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 项目搭建 | Vite + React + TypeScript配置 | 1天 |
| 游戏引擎核心 | GameLoop, Scene, Entity基类 | 3天 |
| 渲染系统 | Canvas渲染, 精灵动画 | 2天 |
| 输入系统 | 触摸3区域检测 | 1天 |
| 碰撞系统 | 矩形碰撞检测 | 1天 |
| 摄像机系统 | 跟随+视差背景 | 1天 |

**里程碑**: 可以控制角色移动和跳跃

### 第二阶段: 核心玩法 (2-3周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 玩家系统 | 生命值、攻击、技能CD | 2天 |
| 技能系统 | 技能1/技能2实现 | 3天 |
| 敌人系统 | 敌人AI、生成管理 | 3天 |
| 战斗系统 | 伤害计算、击杀判定 | 2天 |
| 道具系统 | 掉落、拾取、效果 | 2天 |
| 连击系统 | 连击计数、加成 | 1天 |
| 分数系统 | 实时计分、最终结算 | 1天 |

**里程碑**: 完整的战斗跑酷循环

### 第三阶段: 角色与内容 (2-3周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 角色配置系统 | 从JSON加载角色数据 | 1天 |
| 12个MVP角色 | 动画集成、技能实现 | 6天 |
| 3个MVP赛道 | 背景、障碍物配置 | 3天 |
| Boss系统 | Boss AI、多阶段战斗 | 3天 |
| 技能特写演出 | 切入动画系统 | 2天 |

**里程碑**: 12角色、3赛道可玩

### 第四阶段: UI与体验 (1-2周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 主菜单界面 | 开始、设置、角色选择入口 | 1天 |
| 角色选择界面 | 角色网格、预览、确认 | 2天 |
| 赛道选择界面 | 赛道列表、预览 | 1天 |
| 游戏HUD | 生命条、分数、技能CD | 1天 |
| 暂停/结算界面 | 暂停菜单、结果展示 | 1天 |
| 成就界面 | 成就列表、解锁状态 | 1天 |
| 音效集成 | BGM、音效播放 | 1天 |

**里程碑**: 完整UI流程

### 第五阶段: 联网与社交 (1周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 排行榜API | 分数提交、查询 | 1天 |
| 排行榜UI | 排名列表展示 | 1天 |
| 分享功能 | 生成分享卡片 | 2天 |
| 微信适配 | JSSDK集成 | 1天 |

**里程碑**: 可分享、有排行榜

### 第六阶段: 优化与测试 (1周)

| 任务 | 描述 | 预估时间 |
|------|------|---------|
| 性能优化 | 帧率稳定、内存优化 | 2天 |
| 兼容性测试 | 多设备测试 | 2天 |
| Bug修复 | 测试反馈处理 | 2天 |
| 最终调优 | 数值平衡、体验优化 | 1天 |

**里程碑**: MVP发布
