# 赛道背景Prompt完整列表

## 背景规格说明

每条赛道需要4层视差背景：
| 层级 | 尺寸 | 滚动速度 | 描述 |
|------|------|---------|------|
| Layer 1 | 640×360 px | 0.2x | 远景背景 |
| Layer 2 | 640×360 px | 0.5x | 中景元素 |
| Layer 3 | 640×360 px | 0.8x | 近景装饰 |
| Layer 4 | 640×64 px | 1.0x | 地面层 |

**通用要求**: 无缝水平循环 (seamless horizontal tile)
